# El Son del Obrero - Landing Page SEO

Incluye:
- Diseño responsive.
- Reproductor de streaming preparado.
- Espacios publicitarios.
- SEO técnico: title, description, keywords, robots y canonical.
- Open Graph para WhatsApp/Facebook.
- Twitter/X Cards.
- Schema.org para RadioStation y WebSite.
- sitemap.xml y robots.txt.
- Favicon y manifest.
- Imágenes optimizadas a WebP.
- Alt text y lazy loading.

IMPORTANTE:
El dominio de ejemplo es https://www.elsondelobrerocali.com/
Antes de publicar, reemplázalo por el dominio real en index.html, robots.txt y sitemap.xml.

STREAMING:
En index.html busca const STREAM_URL = "";
y coloca allí la URL real del streaming.

REDES SOCIALES:
Cuando el cliente entregue las URLs oficiales, agrégalas al campo sameAs del Schema.org.

PUBLICIDAD:
Los bloques .ad-slot están listos para reemplazarse por los banners reales.
